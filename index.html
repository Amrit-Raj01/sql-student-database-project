Student Database Management System

SQL Project using MySQL

Project Overview

This project demonstrates a Student Database Management System designed using MySQL. It manages students, courses, and enrollment data and performs real-world academic analysis.

Database Tables

  • Students
  • Courses
  • Enrollments

Sample SQL Query

SELECT s.name
FROM students s
JOIN enrollments e ON s.student_id = e.student_id
WHERE e.marks < 40
GROUP BY s.name
HAVING COUNT(*) > 2;
